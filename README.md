# AbdullahBlog

AbdullahBlog is a modern and responsive blog website built using **Next.js** and **Tailwind CSS**.  
It includes markdown-based blog posts, dynamic routing, theme toggling (light/dark/system), and a clean UI for developers and tech readers.

---

## ✨ Features

- 🧭 Multi-page layout: Home, About, Blog, Contact
- 🌗 Dark / Light / System mode toggle
- 📝 Markdown-based blog posts
- 🖼️ Responsive design with Tailwind CSS
- 🔐 Login & Signup UI (non-functional demo)
- 📦 Easy to expand and customize

---

## 🚀 Technologies Used

- [Next.js](https://nextjs.org/) – React framework for production
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
- [React Icons](https://react-icons.github.io/react-icons/) – Icons
- [MDX / Markdown support] – For blog content

---

## 📂 Pages Overview

- `/` – Home page with hero section, pricing, testimonials, and featured blogs
- `/about` – Developer profile and coding journey
- `/blog` – List of blog cards with clickable detail pages
- `/contact` – Placeholder for contact page
